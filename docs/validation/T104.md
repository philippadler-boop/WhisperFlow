## Requirement

> T104: Add the `qa-agent` job skeleton to
> `.github/workflows/claude-agents-pipeline.yml`: no `github_token` input,
> `anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY_QA }}` per ADR 0008,
> `--agent qa --model sonnet --allowedTools "<qa.md's exact tools: line>"`
> per FR-005/FR-012 (read `.claude/agents/qa.md` to get the exact list —
> do not paraphrase it) — trigger condition left as `if: false` placeholder
> for now, wired for real in Phase 5 (ADR 0008, ADR 0009)

This decomposes into 7 checkable sub-requirements:

1. `qa-agent` job exists exactly once, alongside (not replacing)
   `dev-agent`/`reviewer-agent`.
2. Job-level `if: false` placeholder, evaluating as a real boolean, not a
   string.
3. `anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY_QA }}` — exact value,
   with no fallback to `ANTHROPIC_API_KEY_DEV` or
   `ANTHROPIC_API_KEY_REVIEWER` (ADR 0008's no-fallback guarantee).
4. No `github_token` input on the step.
5. `claude_args` contains `--agent qa --model sonnet --allowedTools
   "Read,Bash,Grep,Glob,Write"` — matching `.claude/agents/qa.md`'s own
   `tools:` line verbatim (order and all), and genuinely different from
   `reviewer-agent`'s narrower `Read,Grep,Glob` grant.
6. Job structure (separate job, own `permissions:`, no checkout/push step
   yet) matches ADR 0009's decision and is structurally consistent with
   the already-merged `reviewer-agent` skeleton (T103).
7. No regressions: full test suite and lint remain clean.

This matches ADR 0009's Decision exactly: "Three jobs, one workflow file

read` with no write/checkout step also matches the code comment's own
stated rationale (Phase 5/T117 adds the checkout-and-push step; not
added preemptively). The `if: false` placeholder matches ADR 0009's
statement that the real trigger (`pull_request_review`/`approved`) is
deferred, and the code comment in the workflow file itself correctly
attributes this to T116/Phase 5. **PASS.**
