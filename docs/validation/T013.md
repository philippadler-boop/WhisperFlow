## Requirement Evidence

### Transcript segments -> ordered standard SRT - FR-003, FR-006 / T012

Command:

```text
inline Python probe calling write_subtitles() and parsing the result with srt.parse()
```

Observed:

```text
SRT_BLOCKS= [(1, 0.0, 1.5, 'First line'), (2, 1.5, 3.2, 'Second line')]
```

The result was written to a nested output path, parsed as two standard SRT
blocks, preserved source-language text, and retained the ordered timings and
1-based indices.

**PASS** - T012 converts each transcript segment 1:1 and writes a valid,
ordered `.srt` file.

### Ordered pipeline and progress reporting - FR-011 / T013

Command:

```text
inline Python probe calling run_pipeline() with probe/extract/transcribe
boundaries exercised, then advancing the returned reporter
```

Observed:

```text
STAGE_OUTPUT= 'Extracting audio...\nTranscribing...\nWriting subtitles...\n'
STAGE_ORDER= [0, 18, 32]
REPORTER_BEFORE= WritingSubtitles
REPORTER_AFTER= Done
```

The actual implementation output used the contract's Unicode ellipsis in
the stage labels; the displayed command result is represented here with
ASCII ellipses. The indices prove the required stage order. The reporter
returned by `PipelineResult` allowed the caller to complete the same job's
terminal transition.

Independent real-fixture command:

```text
run_pipeline(tests/fixtures/clear_speech.mp4, model_size='tiny')
```

Observed for the clear-speech fixture: `has_speech=True`, `srt_blocks=1`,
output exists, terminal stage `Done`, and all three stage announcements plus
transcription progress were present.

**PASS** - T013 runs probe -> extract -> transcribe -> write, reports stages
and progress, and returns a usable reporter handoff.

### No detectable speech, including no audio track - FR-008 / T013

Independent real-fixture command:

```text
run_pipeline(tests/fixtures/silence.mp4, model_size='tiny')
```

Observed:

```text
has_speech=False, srt_blocks=0, output_exists=True, terminal_stage='Done', notice=True
```

An additional direct probe supplied a probed `Video(has_audio_track=False)`.
Observed:

```text
NO_AUDIO= False  True False
```

The blank field is the empty SRT content; the following `True False` values
mean the no-speech notice was present and `Error:` was absent. Extraction and
transcription were not called in this branch.

**PASS** - Both silent audio and an absent audio track produce a successful
empty `.srt` and a clear no-speech notice, not a failure.

### Domain failures and subtitle-write failures - FR-007 contract / T013

Direct failure probes forced a transcription domain error and an output
write `OSError`.

Observed:

```text
DOMAIN_FAILURE= TranscriptionError True Failed
WRITE_FAILURE= SubtitleWriteError True True temp_exists= False
```

The first result confirms a domain transcription error was re-raised and
reported through the failure path. The second confirms an `OSError` became a
`SubtitleWriteError`, included its reason (`disk full`), emitted an `Error:`
line, and left no extracted temporary audio.

**PASS** - Expected processing failures are clearly reported as domain
errors; output-write failures do not escape as raw filesystem errors.

### Temporary-audio cleanup and primary-error precedence - data-model / T013

The real success and silence runs completed with pipeline-owned temporary
audio removed. Focused failure tests and direct probes also covered
transcription failure, subtitle-write failure, and cleanup failure.

Observed direct cleanup-precedence result:

```text
CLEANUP_PRIMARY= TranscriptionError True cleanup_masked= False
```

This forced cleanup to raise `PermissionError` while transcription raised the
primary `TranscriptionError`; the primary error was preserved and the cleanup
failure did not mask it. The focused pipeline test also verified cleanup
failure after an otherwise successful run is reported as
`AudioExtractionError`.

**PASS** - Temporary audio is cleaned up on the exercised success,
transcription-failure, and write-failure paths; cleanup failures are surfaced
when primary processing succeeds and do not replace a primary failure.
