### FR-008: no speech is a successful run with an empty subtitle file and clear notice

Independent direct CLI command:

```text
whisperflow transcribe <temporary directory>/silence.mp4 --model tiny --no-review
```

Observed:

```text

STDOUT_BEGIN
STDOUT_END
STDERR_BEGIN
Extracting audio...
Transcribing...
Writing subtitles...
No speech detected in the input video -- wrote an empty subtitle file.

STDERR_END

SRT_BYTES=0
SRT_CONTENT_BEGIN
SRT_CONTENT_END
```

The command used the real installed executable and real silence fixture. The
subtitle file existed and was exactly zero bytes, which is a valid empty SRT;
stdout was empty; and stderr clearly explained that no speech was detected and
that an empty subtitle file was written.

**PASS** - The observed exit status, file result, and stderr notice satisfy
FR-008.

### FR-011: stage/progress information remains consistent for the no-speech run

Combined focused command:

```text
python -m pytest tests/integration/test_progress.py tests/integration/test_no_speech.py -q -vv
```

Observed:

```text
tests/integration/test_progress.py::test_transcribe_reports_stage_and_progress_lines_on_stderr PASSED [ 50%]
tests/integration/test_no_speech.py::test_silent_video_succeeds_with_empty_srt_and_stderr_notice PASSED [100%]

```

The direct no-speech stderr contained the applicable pipeline stages
`Extracting audio...`, `Transcribing...`, and `Writing subtitles...` before
the no-speech notice and completion line. The neighboring progress integration
test independently passed its exact contract assertions for the Unicode stage

percentage is not expected for the no-speech case because no transcript
segments are produced; the no-speech run still reports each applicable stage
and its successful outcome on stderr.

The PowerShell capture rendered the Unicode ellipsis as `à` due to console
encoding, while the in-process focused progress test passed against the exact
Unicode ellipsis contract strings used by the application.

**PASS** - The no-speech run reports applicable stage information and a clear
successful outcome consistently with FR-011; the general progress contract is
also independently covered by the neighboring integration test.
