## Requirement

> T028: Extend the benchmark helper (depends on T025, same file) to
> measure transcription accuracy and subtitle-sync percentage against a
> small labeled sample corpus, giving QA concrete data points for SC-003
> (≥90% accuracy) and SC-004 (≥95% sync) in `scripts/benchmark.py`.

Exact spec.md wording checked directly (`specs/001-video-subtitle-generator/spec.md`):

> **SC-003**: At least 90% of generated subtitle lines, for clear speech
> in a supported language, are judged by a reviewing user to accurately
> reflect what was actually said.
>
> **SC-004**: At least 95% of generated subtitle lines are perceived by a
> viewer as in sync with the spoken audio (no noticeable lag or lead).

Both are explicitly human-judgment criteria in spec.md's own wording;
`scripts/benchmark.py`'s docstring and the printed report both state this
script is a proxy/anchor for `qa`, not a certification of SC-003/SC-004
themselves. Since T025 already delivered the raw accuracy/sync
computation, T028's genuinely new surface — and this validation's actual
scope per the task prompt — is: explicit `sc003_note()`/`sc004_note()`
verdicts, `--min-accuracy`/`--min-sync-ratio` CLI options, `--strict`'s
distinct exit code, and the two review-round fixes, all re-verified
end-to-end against real (not mocked) runs.

This decomposes into 7 checkable sub-requirements matching the task
prompt's own steps 3-7:

1. Real corpus run against the checked-in fixture prints correct
   SC-003/SC-004 verdict lines.
2. `--strict` with a deliberately impossible threshold exits with status
   `3` (not 1 or 2) and clearly states the miss.
3. Review fix #1 (vacuous `overall_sync_ratio`) holds under a real,
   disposable zero-speech corpus — SC-004 reports "could not be
   evaluated," not a false "meets target."
4. argparse's own usage-error exit code is still genuinely `2`,
   unaffected by this PR.
5. `tests/unit/test_benchmark.py` passes (58 tests, per the PR's own
   claim).
6. `pytest -q` (full suite) shows no regressions.
7. Traceability: PR references FR/issue correctly (informational).
