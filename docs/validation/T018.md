## Requirement: FR-007 unsupported input

**Requirement:** An unsupported or invalid video must fail with exit code 1,
clearly report the error, and leave no partial subtitle output.

**Evidence:** Direct CLI invocation against a temporary `input.txt`:

```text
unsupported.exit_code= 1
unsupported.stdout= ''
unsupported.stderr= "Error: could not determine a supported video format for '...\\input.txt' (supported formats: mp4, mov, mkv)\\n"
unsupported.output_exists= False
```

The focused integration test additionally verifies one non-empty stderr line,
the `Error: ` prefix, the established `supported video format` wording, and
the absence of the requested `.srt` file.

**Result:** PASS

## Requirement: FR-007 over-two-hour video

**Requirement:** A video exceeding the two-hour maximum must fail with exit
code 1, clearly identify the maximum and detected duration, and leave no
partial subtitle output.

**Evidence:** The validation command generated a temporary MP4 with `ffmpeg`
and verified `ffprobe` duration `7201.000000` seconds. Direct CLI output was:

```text
fixture.returncode= 0
fixture.duration_seconds= 7201.000000
overlong.exit_code= 1
overlong.stdout= ''
overlong.stderr= 'Error: video exceeds maximum supported length of 2 hours (got 2:00:01)\\n'
overlong.output_exists= False
```

The focused integration test additionally verifies one non-empty stderr line,
the `Error: ` prefix, `maximum`, `2 hours`, and `2:00:01`.

**Result:** PASS
