### 3. Job structure matches ADR 0008 and ADR 0009 (both `Accepted`)

Read `docs/adr/0008-api-key-routing.md` and
`docs/adr/0009-workflow-job-structure-and-triggers.md` directly; both
carry `> **Status**: Accepted` headers (not `Proposed`).

- ADR 0008 requires: "Each of the three automation-mode
  `claude-code-action` invocations (`developer`, `reviewer`, `qa`) is its
  own independent step in its own job, with a literal, hardcoded
  `anthropic_api_key: ${{ secrets.<ROLE_KEY> }}` reference" and "No shared
  variable, no YAML anchor/alias, no computed/dynamic secret-name lookup,
  and no `||` fallback expression." The live file's `reviewer-agent` job
  has exactly one step, one literal `anthropic_api_key:
  ${{ secrets.ANTHROPIC_API_KEY_REVIEWER }}` line, no anchor/alias/`||`
  anywhere in the job. **Matches.**
- ADR 0009 requires: "Three jobs, one workflow file: `dev-agent`
  (existing, unchanged)... plus two new jobs, `reviewer-agent` and
  `qa-agent`, each independently gated by its own `if:` condition,
  granted only its own role's tools/secret/permissions... rather than
  appending more steps to the existing `dev-agent` job." The live file has
  `dev-agent` unchanged and a separate `reviewer-agent` job with its own
  `if:`, its own `permissions: contents: read` (minimal, read-only — no
  `write` anywhere, consistent with ADR 0009's rationale that no
  checkout/diff-fetch step exists yet at this skeleton stage), and its own
  tool/secret grant. T103 itself is explicitly the "job skeleton only"
  step of this ADR's plan (the real `pull_request`/`opened,synchronize`
  trigger is T106, Phase 3, not yet done here) — the live `if: false`
  placeholder is consistent with that phasing, not a shortcut around it.
  **Matches.**
- FR-002/`contracts/automation-triggers.md`'s tool-grant table (read
  directly at `specs/002-reviewer-qa-automation/contracts/automation-triggers.md`)
  states: "`reviewer` (new automation-mode) | `Read,Grep,Glob` | `Write`,
  `Edit`, `Bash`, `git`, `gh`" must not be included. The live
  `claude_args` string contains none of `Write`, `Edit`, `Bash`. **Matches.**

**PASS** on all three source documents.
